# Modifications par rapport à main

## Système de transmutation

- Table d'alchimie transformant un item en variantes similaires (style Blue Skies)
- Catalyseur requis : glowstone dust, diamond, bone meal, echo shard ou amethyst shard
- Recettes affichées dès que l'ingrédient correspond ; résultat affiché uniquement avec catalyseur valide
- Tooltip indiquant le catalyseur requis sur les résultats
- Support des tags Forge pour compatibilité mods (`results_tag`)

## Transmutations disponibles

**Colored** : bannières, lits, tapis, béton, poudre de béton, verre, vitres, shulker boxes, terracotta, laine

**Stone** : pierre (stone, granite, diorite, etc.), briques de pierre, murs

**Wood** : planches, barrières en bois, bois (bûches), bois écorcé

**Nature** : pousses

**Nether** : Soul Sand → Soul Soil

## Données

- Tags Forge créés/étendus : planks, wool, terracotta, stone, stone_bricks, glass, glass_panes, fences, walls, logs, stripped_logs, etc.
- Tags créés (non fournis par Forge) : `forge:walls`, `forge:logs`, `forge:stripped_logs`
